# Nexa Responsive Landing Page

A Level 1 internship project built with semantic HTML5, CSS3, and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive layout, styling, and reduced-motion support
- `script.js` — mobile navigation, reveal animations, and dynamic footer year

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. For development, use VS Code with the Live Server extension.

## Customize
- Change the brand name, copy, and email address in `index.html`.
- Change colors in the `:root` section at the top of `style.css`.
- No build tools or frameworks are required.

The Google Fonts import requires an internet connection; system fallback fonts are provided.
